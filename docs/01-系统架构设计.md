# 黔能碳溯 · 系统整体架构设计（v2 · 按更新后需求重新优化）

> 贵州省重点产业碳足迹双轨合规与多级溯源智能系统
> 前后端分离 · 单体极简部署 · 两周极速交付
> 四角色：企业端 / 省厅监管端 / 第三方核查机构端 / 超级管理员端 + 公开验真页（免登录）

---

## 0. 技术选型（v2 决策）

| 层 | 选型 | 决策理由 |
| --- | --- | --- |
| 后端 | **Spring Boot 3 + JDK 17（单体）** | 用户熟悉 Java + MyBatis；MyBatis-Plus 单表 CRUD 零 SQL、分页插件，两周内出活最快；后续项目/简历/团队协作延续 Java 体系 |
| 数据访问 | MyBatis-Plus | 免写基础 SQL，内置分页/逻辑删除/代码生成 |
| 鉴权 | Spring Security + JWT + Redis | 签发 Token、接口权限校验、登录态管理（Token 白名单 → 支持踢人下线）、验证码 |
| 数据库 | MySQL 8.0 + Redis | MySQL 业务数据（事务/索引）；Redis 仅做 Token 与字典缓存 |
| 前端 | Vue 3 + Vite + Element Plus + ECharts + Pinia + qrcode.vue + Axios | 官方指定组合 |
| 哈希/防伪 | SHA-256（JDK 自带） | 哈希链存证、护照验真签名，不引入第三方库 |
| 部署 | Nginx + Spring Boot + MySQL + Redis（单机 Docker Compose） | 一轮命令起全栈 |

## 2. 功能模块矩阵（三块之一：输入 → 处理 → 输出）

### 企业端（煤矿 / 新能源材料工厂）

| 模块 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 碳数据填报 | 月度原煤消耗量、用电量、运输周转量、产量 | 按范围一/二/三分类存储，校验必填项 | 活动数据记录 |
| 化验单识别 | 化验单照片 | **多模态视觉大模型读图**，抽取灰分、硫分、低位发热量等 | 结构化化验数据，人工确认后入库 |
| 碳排核算 | 活动数据 + 因子库 | 相乘汇总，按月份/范围/排放源分组 | 核算明细 + 总量 + 碳强度 |
| 核算报告 | 核算结果 | ECharts 生成饼图、柱状图、趋势图 | 可下载的报告页 |
| AI 碳管家 | 自然语言提问 | 带企业上下文调用大模型（SSE 流式） | 政策解读、核算方法问答 |
| 护照申请 | 核算期、报告 | 状态机流转 | 进度条：填报 → 省审 → 复核 → 发证 |
| 供应链协同 | 供应商名称、资质、合同 | 表单登记、附件上传 | 供应商档案 |
| 物流追踪 | 车牌、起终点 | **高德地图 JS API** 画模拟轨迹 | 轨迹图 + 里程 |
| 绿色金融 | 历史核算、申报记录 | 计算信誉分与预授信额度 | 雷达图 + 授信申请单 |
| 出海数据包 | 核算结果 | 按 CBAM 报表模板拼装 | Excel 数据包 |

### 省厅监管端

| 模块 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 态势大屏 | 全省企业核算数据 | 按市州汇总、实时刷新 | 贵州热力图、滚动数字、行业排行 |
| 智能初审台 | 企业提交的核算 | 与历史数据、行业基准比对 | 异常标红清单 + 预警原因 |
| 核查派单 | 异常企业、核查员 | 生成核查任务 | 任务列表 |
| 移动执法 H5 | GPS 坐标、现场照片 | 校验定位是否在企业范围内 | 打卡记录 + 照片 |
| 因子库管理 | 燃料、电力、运输因子 | 增删改查（版本/生效状态） | 省级因子库 |
| 电子签章 | 初审通过的申请 | 印章图片叠加到审批单 | 带章的初审意见书 |

### 第三方核查机构端

| 模块 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 数据包接收 | 企业出海数据包 | 列表展示、下载 | 待复核清单 |
| 国际标准复核 | 核算明细 | 核对方法学、因子、边界 | 复核意见：通过/退回 |
| 护照签发 | 复核通过记录 | 生成护照编号、写哈希链、生成二维码 | 碳足迹护照 |

### 超级管理员端

| 模块 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| RBAC 权限 | 用户、角色、菜单 | 用户绑角色、角色绑菜单 | 登录后按权限渲染菜单 |
| 系统监控 | 服务器指标、在线用户 | 定时采集 | 监控看板 |
| 审计日志 | 每次关键操作 | 记录操作人、时间、前后值 | 日志列表 |
| 哈希链监控 | 存证记录 | 展示链、一键验链 | 链列表 + 验链结果 |

### 公开页（无需登录）

| 模块 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 扫码验真 | 二维码（护照 token） | 比对护照记录 + 哈希链存证 | 护照信息、核算汇总、存证哈希、是否被篡改 |

| 高德地图 JS API | 物流轨迹 | 地图底图、划线 |

## 6. 核心业务闭环

```
填报活动数据(范围1/2/3) + 化验单多模态识别 → 碳排核算(因子相乘汇总)
  → ECharts 核算报告 → CBAM 数据包 → 护照申请(状态机)
  → 省厅智能初审(异常比对预警 → LLM 生成说明) → 核查派单/H5打卡(电子签章)
  → 第三方国际复核 → 护照签发(编号 + SHA-256哈希链 + 防伪二维码)
  → 公开页扫码验真(护照信息/核算汇总/存证哈希/是否被篡改)
  全程：审计日志留痕 + 哈希链存证 + 绿色金融信誉分联动
```

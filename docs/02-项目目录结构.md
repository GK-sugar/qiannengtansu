# 黔能碳溯 · 项目目录结构树状图（v2 · Spring Boot 3）

> 单仓（Monorepo）：`backend`（Spring Boot 3 + JDK17 单体）+ `frontend`（Vue3 SPA）+ `sql` + `deploy` + `docs`
> H5 执法打卡复用前端 `/m/checkin`；公开验真页 `/verify/:token` 免登录。

```
黔能碳溯/
├── README.md                          # 启动步骤 / 端口 / 默认演示账号
├── docs/
│   ├── 01-系统架构设计.md
│   ├── 02-项目目录结构.md
│   ├── 03-外部API与资源清单.md
│   └── 04-公式与算法说明.md            # F1~F12 公式的含义与用法
├── sql/
│   └── init.sql                        # MySQL 8.0 DDL（52 张表 + 初始角色/字典，v1.3 含国家级 4 张新表）
├── deploy/
│   ├── docker-compose.yml              # nginx + backend + frontend + mysql + redis
│   ├── nginx.conf                      # 反代 / SSE(LLM流式) 超时
│   └── .env.example
├── backend/                            # ===== Spring Boot 3 单体（JDK 17）=====
│   ├── pom.xml                         # spring-boot 3.x / mybatis-plus / security / redis
│   └── src/
│       ├── main/java/com/qnct/
│       │   ├── QnctApplication.java    # 启动类（@SpringBootApplication）
│       │   ├── common/                 # Result<T> / PageResult / 业务异常 / 常量
│       │   ├── config/                 # SecurityConfig / MybatisPlusConfig / RedisConfig / CorsConfig / AsyncConfig
│       │   ├── security/               # JwtUtil / JwtAuthFilter / LoginUser / UserDetailsServiceImpl / Security 握手
│       │   ├── controller/
│       │   │   ├── AuthController.java # 登录/登出/验证码/me（验证码走 Redis）
│       │   │   ├── enterprise/         #   EnergyData(填报)/LabReport(多模态)/CarbonCalc/Report/Package/
│       │   │   │                        #   AiSteward(SSE)/Passport(申请追踪)/Supplier(协同)/Logistics(物流)/
│       │   │   │                        #   Finance(绿色金融)/Rectify(整改计划与预算)
│       │   │   ├── gov/                #   Screen(大屏)/Review(初审台)/Inspection(派单)/Checkin(H5打卡)/
│       │   │   │                        #   Factor(因子库)/Seal(电子签章)
│       │   │   ├── agency/             #   PackageReceive / Review(国际复核，复核后推送国家级终审)
│       │   │   ├── national/           #   NationalFinalIssue(终审签发)/NationalMonitor(跨国互认)/NationalForecast(宏观预测)/
│       │   │   │                        #   NationalTariff(关税预警)/NationalBlacklist(黑名单通报)
│       │   │   ├── admin/              #   Rbac(权限中心) / AuditCenter(全链路审计与存证) / Dict / Monitor
│       │   │   └── PublicController.java # /verify 公开验真(免登录)
│       │   ├── service/ + service/impl/  # 业务逻辑（按域分包）
│       │   │   ├── CarbonCalcService    # 核算引擎 F1~F5
│       │   │   ├── HashChainService     # SHA-256 哈希链/验链 F10
│       │   │   ├── PassportService      # 护照状态机 + 验真签名 F11
│       │   │   ├── RuleEngineService    # 初审波动 F6
│       │   │   ├── CreditScoreService   # 绿色金融 F7/F8
│       │   │   ├── GeoService           # Haversine 打卡判定 F9 + 高德轨迹
│       │   │   ├── LlmGateway           # 大模型(OpenAI 兼容 SSE)【此处需填入API Key】
│       │   │   ├── VisionGateway        # 多模态读图 qwen-vl【此处需填入API Key】
│       │   │   └── StorageGateway       # 本地/OSS【此处需填入API Key】
│       │   ├── mapper/                  # MyBatis-Plus Mapper 接口

│       │   ├── task/                    # @Scheduled 定时任务: 大屏快照/信誉分/Token巡检
│       │   └── util/                    # Sha256Util / IdGen / JsonUtil...
│       └── main/resources/
│           ├── application.yml          # 端口8082 / MyBatis-Plus配置

│           ├── application-prod.yml
│           ├── db/changelog?            # (简化: 直接执行 sql/init.sql)
│           └── assets/
│               ├── seal/                #   3 枚印章 SVG（政府/核查机构/企业，Codex 自绘）
│               └── templates/           #   护照/意见书/报告模板
└── frontend/                            # ===== Vue3 + Vite SPA =====
    ├── package.json / vite.config.ts / tsconfig.json / index.html
    ├── .env.development / .env.production
    ├── public/
    │   ├── favicon.svg                  # Codex 自绘
    │   └── map/guizhou.json             # 贵州 GeoJSON（DataV 开放数据）
    └── src/
        ├── main.ts / App.vue
        ├── api/                         # Axios 封装 + modules/（LLM 用 EventSource/SSE）
        ├── assets/
        │   ├── logo/                    # logo.svg / logo-white.svg / logo-mark.svg（自绘）
        │   ├── avatar/default.svg       # 自绘
        │   ├── seal/                    # 前端展示用 3 枚印章
        │   └── empty/                   # 空状态插画（自绘）
        ├── components/                  # EChart / StatCard / ModulePage / MapTrack / RadarCard...
        ├── layout/                      # 五端布局（深色侧栏+顶栏，大屏页全屏模式）
        ├── router/                      # 静态路由 + 守卫（登录态/角色权限）
        ├── stores/                      # Pinia: user / permission / app
        ├── styles/                      # 全局设计系统（翡翠绿+深炭主题变量）
        ├── utils/                       # request.ts / demo.ts / auth.ts
        └── views/
            ├── login/                   # 动态背景登录页（Canvas 粒子+极光+玻璃卡片）
            ├── enterprise/              # dashboard / data-fill / lab-vision / carbon-calc /
            │                            # report / ai-steward / passport / supplier /
            │                            # logistics / finance / package / rectify(整改计划与预算)
            ├── gov/                     # big-screen(全屏) / review-desk / inspection /
            │                            # checkin(H5) / factor / seal
            ├── agency/                  # dashboard / review / passport-issue
            ├── admin/                   # dashboard / rbac(权限) / audit-center(审计与存证) / dict / monitor
            ├── national/               # issuance(终审与发证中心) / monitor(跨国互认) / forecast(宏观预测) / tariff(关税) / blacklist(黑名单)
            └── public/                  # verify.vue 公开验真页（路由 /verify/:token）
```

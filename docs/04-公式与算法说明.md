# 黔能碳溯 · 公式与算法说明（第三块产出）

> 每条公式给出「含义 → 用法 → 用在哪」。后端全部由 Java 实现（JDK 自带 SHA-256，核算引擎为纯 Java 计算，可按需在 MyBatis-Plus Service 层落地）。

---

## F1 碳排放基本公式（核算引擎核心）

**E = AD × EF × GWP**

- 含义：排放量 = 活动数据 × 排放因子 × 全球变暖潜势（多数因子已含 GWP，此时 GWP=1）。
- 用法：对每条活动数据（燃煤量、用电量、运输周转量等）查因子库匹配 `emission_factor.factor_value`，相乘得该条记录 CO2e。
- 用在哪：企业端「碳排核算」，写回 `ent_activity_data.emission_co2e`。

## F2 化石燃料燃烧排放（IPCC 完全氧化法，借助化验单）

**E = FC × NCV × CC × OF × 44/12**

- 含义：排放 = 燃料消耗量 × 低位发热量 × 单位热值含碳量 × 碳氧化率 × (CO2 与 C 分子量比 44/12)。
- 用法：`NCV`（低位发热量）来自化验单 OCR/多模态识别的字段；CC 默认 26.37 tC/TJ（缺省值），OF 取 0.9~1。
- 用在哪：煤矿自用煤核算；体现「化验单识别 → 核算」的业务闭环。

## F3 外购电力隐含排放

**E = AD电 × EF电网 / 1000**

- 含义：排放 = 用电量 × 区域电网平均排放因子（kgCO2e/kWh）。
- 用法：`AD电` 单位 kWh，EF 取省级因子库「电力」因子（如 0.5703 tCO2e/MWh，可被省厅修订）。
- 用在哪：Scope 2 核算（购电），由省厅因子库管理版本。

## F4 运输环节排放

**E = Σ ( 载重 t × 里程 km ) × EF运输**

- 含义：排放 = 货物周转量 × 运输方式排放因子。
- 用法：物流追踪根据车牌起终点在高德地图画出轨迹并求和里程，按「公路/铁路/水运」匹配因子。
- 用在哪：Scope 3 运输排放 + 企业端「物流追踪」里程统计。

## F5 总量与碳强度

**E总 = Σ E范围1 + Σ E范围2 + Σ E范围3**

**I = E总 ÷ Q产品**

- 含义：总碳足迹 = 三个范围之和；碳强度 = 总排放 ÷ 产品产量（功能单位 1t / 1kWh / 1kg）。
- 用法：核算明细按「月份/范围/排放源」分组求和，强度用于横向对标与护照展示。
- 用在哪：核算报告、态势大屏排行、碳足迹护照核证数值。

## F6 智能初审异常波动

**波动率 r = |X本期 − X基准| ÷ max(X基准, ε)**

- 含义：本期数值相对基期（历史均值/行业基准）的相对偏离。
- 用法：r > ±20%（`sys_config: rule.anomaly.default_threshold`）判定异常；越级超 3σ 或强超阈值升为高等级预警。
- 用在哪：省厅「智能初审台」异常标红 + 预警原因生成（LLM 可辅助写说明）。

## F7 绿色金融信誉分

**S = 40×A数据完整度 + 25×B数据及时性 + 20×C核算稳定性 + 15×D历史合规**

- 含义：四项加权信用评分（0~100），衡量企业碳数据可信度。
- 用法：A = 已填报月份/应填报月份；B = 按时提交率；C = 1 − 平均波动率；D = 无退回记录比例。
- 用在哪：企业端「绿色金融」雷达图 + 预授信额度计算。

## F8 预授信额度

**Q = Q基准 × k等级**

- 含义：预授信额度 = 基准额度（按行业规模分档）× 信誉等级系数。
- 用法：S≥90 → k=1.0（AAA）；80~89 → 0.85；70~79 → 0.7；<70 → 0.5。
- 用在哪：绿色金融授信申请单初值，供金融机构参考。

## F9 打卡离场判定（Haversine 球面距离）

**d = 2R·arcsin(√(sin²(Δφ/2) + cosφ1·cosφ2·sin²(Δλ/2)))，R=6371km**

- 含义：两经纬度点的球面大圆距离。
- 用法：执法员 GPS 坐标与企业核查点（`gov_inspection_task.lng/lat`）求距，d ≤ radius_m 判有效打卡，否则标记离场。
- 用在哪：移动执法 H5 打卡。

## F10 哈希链防篡改（SHA-256，JDK 自带）

**h_i = SHA256( h_{i−1} ‖ data_i ‖ salt )**

- 含义：每个存证区块 = 上一区块哈希 ‖ 本区块数据（关键字段快照 JSON）‖ 平台盐，单向不可逆、链式牵制。
- 用法：核算结果、报告、护照签发时写入 `sys_hash_chain`；验链时重算并比对，任意篡改导致整链断裂。
- 用在哪：超管「哈希链监控」一键验链 + 公开验真页展示。

## F11 护照验真签名（二维码防伪）

**token = SHA256( passport_no + ":" + site_salt )，取前 16 位展示**

- 含义：以护照编号与平台私盐（`sys_config` 加密存储）生成验真令牌。
- 用法：后端生成 `verify_token` 写入 `carbon_passport`，前端 qrcode.vue 渲染二维码；公开验真页比对 token 与哈希链存证，输出「校验通过/已被篡改」。
- 用在哪：国家级「终审与发证中心」签发（核查机构复核通过后推送终审）、公开页「扫码验真」。

## F12 大屏热力分级

**热力等级 = f( 市州排放量 ÷ 全省总量 )，五级（0-20 / 20-40 / 40-60 / 60-80 / 80-100 分位）**

- 含义：把各市州排放总量映射为地图着色等级与热力点强度。
- 用法：ECharts GeoJSON + visualMap 分级着色，动态数据轮播。
- 用在哪：省厅「态势感知大屏」。


## F13 CBAM 关税影响测算（国家级「国际关税预警」）

**影响额 ≈ Q出口 × I产品 × (1 − f免费配额) × R税率**

- 含义：出口产品的欧盟 CBAM 碳关税成本 = 年出口量 × 单位产品碳排放（tCO₂e/单位产品）× 未获免费配额比例 × 当期税率（€/tCO₂e）。
- 用法：`NationalTariffService` 读取 `nat_tariff_rule`（行业/产品范围/税率/免费配额比例），EU ETS 均价内置基准 71.50 €/tCO₂e；输入出口量与单位产品排放即时测算，输出 CN¥/EUR 折算影响额。
- 用在哪：国家级「国际关税预警」影响测算器（CN¥ 与 € 双币种结论，辅助企业出口风控决策）。


黔能碳溯 · 项目需求说明
碳足迹双轨合规与多级溯源智能系统
一、项目定位
“黔能碳溯”面向贵州省重点产业，提供碳足迹双轨合规与多级溯源能力。系统采用业界主流、现代化的技术栈，打造高标准、高保真的企业级 / 政务级 SaaS 平台，注重业务闭环、AI 能力集成与视觉表现。为适配两周极速开发周期，采用极简单机部署，不引入微服务。前端统一做 Web 端，不开发微信小程序。
二、系统角色
系统为前后端分离架构，包含五类角色，数据按国家 / 省 / 市 / 企业四级隔离：
1. 企业端（Web 端）：普通煤矿 / 新能源材料工厂。
2. 省厅监管端：省级审批部门（Web 大屏 + 移动执法 H5）。
3. 第三方核查机构端：国际合规复核。
4. 国家级审批部门：终审发证、跨国互认与宏观监管。
5. 超级管理员：系统运营端（上帝视角）。

四、技术栈
后端选定 Spring Boot 3 + JDK 17（单体应用）。理由：熟悉 Java 与 MyBatis，MyBatis-Plus 两周内出活最快；FastAPI 虽写接口快，但后续项目、简历与团队协作更可能沿用 Java 体系。
前端：Vue 3 + Vite + Element Plus + ECharts + Pinia + qrcode.vue（仅 Web 端，不做小程序）；数据库：MySQL 8.0 + Redis（仅基础缓存与登录 Token 管理）。
